# Project Proposal Feedback

The project is clearly described and well motivated, and the research question is specific. The use of only booking-time features, a chronological train/validation/test split, and preprocessing fit on the training set are strong points. The main thing to clarify is the prediction target: the research question says "late or cancelled," but section 4.1 and the objectives treat delay and cancellation as two separate tasks, and the objectives only mention delay. Please state whether you will build one combined label or two models, and fix the "ArrDel1" typo (it should be ArrDel15). The goals would also benefit from explicit evaluation metrics and baselines, such as a majority-class baseline and an airline-only model, with F1, PR-AUC, and ROC-AUC reported since delayed flights are the minority class. The weather features need more justification: summaries by month and hour are largely redundant with the month and departure hour features already in the model, so explain how you will test whether they add value (for example, by comparing against a model using actual weather as an upper bound). The weather window is also inconsistent, since section 4.2 mentions 2020-2025 in one place and 2000-2024 in another, so please specify one and make sure the summaries are computed only from training-period data. Since 2020-2021 flights may behave very differently because of COVID, consider testing the models with and without those years. Please also confirm that BTS data for January to July 2026 is already published, since the data is released with a lag. Finally, proofread for small wording issue.
